# stataudit

Check whether a statistical conclusion survives its own data: re-run the analysis, audit each test's assumptions, recompute reported p-values and lint analysis code, including code written with AI assistance.

!!! note "Status: beta"
    Releases are numbered 1.x, but there are no confirmed outside users yet, so details may still change.

```bash
pip install stataudit
```
